# HTML Task

## What is this task?
This task teaches us about the fundementals of HTML and its simple uses.\
like forms and tables and lists and how to construct them using simple html tags.

### Forms
we built a form using the `<form>` tag, and the `<input>` and `<label>` tags.
### List
we built an ordered and unordered list using `<ol>` and `<ul>`
### Tables
we built a table and used the `<table>` and used its attributes like `colspan` and `rowspan` to make the table cells take multiple spans either on the row or the columns.
